# CLI TASK MANAGER 
🔗 📌 PROJECT DESCRIPTION 

2. Project Description
The CLI Task Manager System is a command-line based Python application designed to help users organize and manage their daily tasks efficiently. The program allows users to add tasks, view tasks, mark tasks as completed, and delete tasks using a simple text-based interface

This project demonstrates the use of Python programming concepts such as object-oriented programming (OOP), loops, conditional statements, functions, exception handling, file handling, and JSON data storage. The system stores task data in a JSON file so that tasks remain saved even after the program is closed.

The main objective of this project is to create a practical and user-friendly application while applying intermediate programming concepts in Python.


 ✨ Objectives

The project aims to:

      • Create a command-line task management system
 
      • Apply object-oriented programming concepts

      • Implement file handling using JSON
 
      • Practice loops, conditionals, and functions
 
      • Develop problem-solving and programming skills


 ✨ Features of the System
      • Add new tasks

      • View all tasks
     
      • Mark tasks as completed

      • Delete tasks

      • Save tasks automatically

      • Load saved tasks when the program starts

      • Handle invalid user input
